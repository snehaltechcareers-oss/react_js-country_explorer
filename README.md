🌍 Countries Explorer (React App)

A simple React application that fetches and displays country data using the REST Countries API.
This project is built as a beginner-friendly practice app to learn React fundamentals like components, hooks, API calls, and state management.

🚀 Features
    🌐 Fetches real-time country data from REST Countries API
    🔍 Search countries by name
    🧩 Component-based architecture
    🎴 Grid layout for country cards
    🇺🇳 Displays flag, capital, region, and currency
    📱 Responsive UI design
🛠️ Tech Stack
    React (Functional Components)
    JavaScript (ES6+)
    HTML & Inline CSS
    REST Countries API
📦 Installation & Setup

    Follow these steps to run the project locally:

    1. Clone the repository
        git clone https://github.com/your-username/countries-app.git
    2. Move into project directory
        cd countries-app
    3. Install dependencies
        npm install
    4. Start development server
        npm run dev

🌐 API Used

This project uses the REST Countries API:

https://restcountries.com/v3.1/all?fields=name,cca3,capital,region,flags,currencies
